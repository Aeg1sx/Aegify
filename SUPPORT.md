# Support

Aegify is alpha software maintained on a best-effort basis.

- Use GitHub Discussions or a normal issue for usage questions, reproducible
  bugs, and feature proposals.
- Do not put credentials, proprietary repositories, customer scan output, or
  exploit details in a public issue.
- Use the repository's private vulnerability reporting or Security Advisory
  path for product-security issues as described in `SECURITY.md`.
- Include the version/commit, operating system, minimal owned fixture, command,
  redacted output, and expected behavior when asking for help.

There is no guaranteed response time or commercial support commitment.
