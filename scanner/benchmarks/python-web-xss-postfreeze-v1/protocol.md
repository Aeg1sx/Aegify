# Additional public product patch, frozen before advisory selection

Frozen scanner source commit fd2e914. Use the already built wheel whose SHA-256 is recorded in scanner/benchmarks/python-web-xss-patches-v1/jinja-defaults.json. Do not change the scanner or rules during this evaluation.

Start with Apache Airflow, then Apache Superset, then Apache Allura in that order. These are maintained public Python web applications independent of pgAdmin, Jupyter Notebook, Flask-Admin and the XBOW cases. Query GitHub's global security advisory database for each PyPI package (apache-airflow, apache-superset, Allura), using cwes=CWE-79, sort=published, direction=asc. Process entries in returned order. Include the first advisory with (1) a published official Apache project CVE notice or official maintainer security advisory, (2) an explicitly linked patch commit or merged upstream pull request, (3) an affected web rendering path in a .py source file in the patch (Flask, Jinja or another server-side HTML rendering path, including a Python API explicitly rendering values as trusted HTML), (4) a corresponding original and repaired Python location. Exclude JavaScript/template-only fixes, unrelated configuration/documentation edits, and changes without a resolvable upstream source patch. Record exclusion reasons. Never skip a case on the basis of a scanner result, a particular Jinja API pattern, or a predicted positive or negative outcome.

For the chosen patch, choose the first eligible .py file in lexical path order and the first relevant HTML-boundary change there in source order. Fix the before and after revision, full module SHA-256, and smallest contiguous old/new expression or statement range relevant to that change before scanning it. Use the existing unmodified evaluator and severity threshold, exact range match for primary CWE-79 and additional out-of-range accounting. Use human review of the public patch only to define labels. Do not execute any application, import source, download additional test fixtures, or run upstream tests. A miss counts. This is one post-freeze product, not an independent assessor or an estimate of general precision.
